spires-postprocess
==================

Postprocessing for SPIReS inversion results: canopy / viewable-fraction
adjustments, snow-albedo and radiative-forcing products, cloud gap-fill, and
tree masking / inpainting.

This package is part of the `SPIReS family <https://spires.readthedocs.io/>`_.
